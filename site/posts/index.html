it works.

You are looking at a fresh zerverg install. Everything on this page — the layout, the colours, the blinking cursor, this very text — is a plain file you can replace.

first steps

  1. Set an admin password and restart (see docs).
  2. Upload a post: PUT /api/v1/posts/my-first-post.
  3. Replace this page: upload your own index page.
  4. Make it yours: upload a stylesheet and activate it.
curl -u admin:secret -X PUT --data-binary @hello.html \
     http://localhost:7080/api/v1/posts/hello

Running with --dev? Authentication is off. Never expose a dev instance to a network you don't trust.
