This is the first post on a brand new zerverg site. It was written as a plain HTML file and uploaded through the API. That is the whole publishing workflow:

vim hello-world.html
curl -u admin:pw -X PUT --data-binary @hello-world.html \
     http://localhost:7080/api/v1/posts/hello-world

No editor in the browser, no plugins, no database. Write HTML with whatever tool you like, and the site wraps it in the active layout and style.

what the metadata looks like

The head of this file carries a few zerverg: meta tags:

<title>hello, world</title>
<meta name="zerverg:date" content="2026-11-15">
<meta name="zerverg:kind" content="post">
<meta name="zerverg:tags" content="zerverg,meta">
Delete this post when you are ready: curl -u admin:pw -X DELETE .../api/v1/posts/hello-world

Happy hacking. / searches.
